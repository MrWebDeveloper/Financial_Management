# Financial Management
**A simple and responsive personal finance manager powered by JavaScript.**

## Features
- Income & Expenses tracking
- Shopping list (To Buy)
- Debts & Credits management
- Live balance with 4 different chart types
- Multi-language support (Persian / English)
- Jalali & Gregorian calendar
- RTL / LTR text direction
- Custom currency
- Multiple themes & fonts
- Data saved in localStorage
- Upload / Download data (JSON)

## Technologies
- HTML
- CSS
- JavaScript
- Local Storage
